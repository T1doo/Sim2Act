# F1 工程增量决定

基线：V5。以下实现不改变 R0/P-A/P-B/增量验证范围。

1. Python 3.12、FastAPI、SQLAlchemy Core、psycopg 与 PostgreSQL；API/worker 独立进程。锁文件固定本轮实际依赖；Windows 版本组合未冻结为已验收。
2. 前端采用包内静态可信页面，不需要 Node 构建。三个一级工作区保持不变；应用清单、发布与实例业务数据在 F2 实现，当前应用列表明确空且 PLANNED。
3. 自建小型持久账本，不引入 LangGraph；租约、授权、幂等与本地事务仍由平台负责。迁移命令显式执行，运行角色不执行 DDL。
4. 本轮资源文本保存在 PostgreSQL，按逻辑资源 ID 授权；数据根目录当前保存 PID/日志。没有将任意路径转成输入文件。后续文件成果原子落位需另测，不声称已经实现。
5. ActionSpec 有严格解析与受信任引用校验；七类 JSON Schema 为草案。F1-2 已补闭合嵌套结构、有限 DAG/引用、输入类型和前置条件；AppManifest 完整编译、类型连通与发布锁定留给后续门，不把结构草案当成可执行发布。
6. 默认 MockModel 只是确定性工程夹具，选择一次注册工具并回填反馈。真实适配器只有书生官方端点与 intern-s2，不引入开发模型。LIVE 能力探针和报告 BLOCKED，未发出真实请求。
7. 请求预约先持久化、以配额主体行锁串行限流；最多 4 请求/4 工具/1 修复。预留字节包络是保守工程预算，不是 tokenizer 实测。真实预算和实际账号限制待批准。
8. 本地效果与 Operation 回执同事务；已核验效果按逻辑调用 ID 回读，旧 fencing token 不得提交。未知模型请求不自动重试；F1-2 已有显式人工核对双路径，导入后暂停，保留未知用量。暂停/取消保留独立意图。
9. F1 工具链的终态为 PARTIAL；独立检查证明读取指纹/本地效果回读，不能证明任意自然语言目标完成。目标验收、两路径和交付图在后续门实现。

## 平台上限（只允许收紧）

HTTP/候选 JSON 64 KiB、JSON 深度 20、文本资源 32 KiB、每任务最多 8 资源、CSV 最多 1000 行、文本成果 8000 字符、输出 1024 Token、总预留 64000、总时限 300 秒、租约 30 秒/独立心跳 10 秒。

## 本轮限制

Windows 原生/PowerShell 尚未运行；缺 LIVE 安全注入与批准预算；语义 oracle、应用 Principal/Release 权限交集、完整清单编译、文件落位恢复、通用未知工具效果核对尚未完成。当前项目运行身份与用户/资源授权交集已用于 F1 工具，但不能据此声称发布应用权限门已经通过。

## F1-2 补充决定

候选校验不保存、授权或执行；AppManifest 仍为不能发布的草案。未知模型请求恢复只绑定原始指纹，人工证据标记 USER_SUPPLIED，不改写成本或取消意图。离线 probe 在加载环境配置之前执行，强制合成传输；真实能力保持 BLOCKED。详见 [Contracts](Contracts.md)、[Reconciliation](Reconciliation.md) 和 [F1-2 TestReport](../evidence/F1-2-TestReport.md)。
