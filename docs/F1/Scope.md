# F1-3 范围核对与验收前置

依据：V5 产品 §5.1—5.6/§8；阶段计划 §3 F1-T01/T04/T05/T07 及 §4 F2-T01—T09。原文保留在 sources/V5；以下是实施划分，不改验收标准。

| 需求 | 阶段归属与本轮边界 |
| --- | --- |
| 最小契约、注册引用、输入/权限/预算预检 | F1；提供纯候选 preflight，不保存可执行计划、不运行、不发布 |
| 目标、输入快照、运行配置持久化和幂等接受 | F1；手动任务接受时冻结 GoalSpec 和 F1-tool-chain.v1 检查版本，语义目标验收仍 NOT_RUN |
| 未知结果、取消意图、可信工具回读和账本 | F1；支持当前三种可信本地工具，未知适配器没有证据则仍 OUTCOME_UNKNOWN |
| 目标卡已知/假设/硬约束与语义验收 | F2-T01；当前只冻结用户提交的目标，不实现模型目标卡或语义 oracle |
| P-A/P-B、实际节点编译执行、条件分支运行器 | F2-T02—04；本轮无执行计划/运行器，不能把拓扑预检当正式应用编译成功 |
| 应用 Principal、Release 锁定、预览/发布、实例数据 | F2-T05/08；项目运行授权预检不能替代应用发布权限交集 |
| 文件生成/原子落位、跨文件与数据库窗口 | F2-T06/09；当前真实副作用是同一 PostgreSQL 事务内的文本资源，不新增文件执行路线 |
| 真正外部接口幂等与恢复 | R0真实业务禁用；本轮未知适配器的故障注入验证保守等待，不冒充真实外部核对 |
| AT-18 应用并发 | F2；未新增应用并发开发。既有领任务专项属于F1队列互斥 |

本轮列出的三个独立 F1 工程缺口已补齐，停止扩大底座；F1 门仍依赖以下验证，不由 MOCK 放行。

## 外部验证步骤（当前未执行）

1. 目标 Windows 11 x64 原生 + Python 3.12 x64 + PowerShell 7 + PostgreSQL；记录准确版本/build。按 README 用独立迁移角色初始化，再给运行角色业务表权限；Doctor/Start 检查 API/worker/数据库/目录，重复 Stop/Start 并跑工程用例与 AT-01。不能用 WSL/Linux 替代，不能宣称当前原生 PASS。
2. 用户在本机私有配置注入书生 token、账号配额主体及明确批准预算，停止共享账号的并行测试。先 Doctor，确认运行身份和数据授权；将模式明确设为 LIVE 后只提交一项有限合成任务，记录请求/返回模型、正式可见模型与参数快照、工具反馈修订、完整失败成本/预约、429/用量未知。没有安全配置和批准预算时不运行。当前 CLI probe **只有离线模式**，不是可直接执行的 LIVE 探针；真实模型列表和账号能力采集/编排仍未验收，不从离线报告推断通过。
3. 取得真实材料授权及独立验收者；C0 截止/时区、体验链接形式、托管模型文件要求、参赛主体/成员需赛方/负责人答复并保存来源。

Windows、LIVE、真实材料与赛方规则均是当前 BLOCKED/待核实项。F2完整应用能力保持PLANNED；取得外部条件后先完成 F1 验证，再决定后续阶段。

## 跨平台客户端目标补记

响应式网页客户端应覆盖Windows/苹果/Android等使用场景，窄屏与触控需专项核查；当前记录的是目标，不能将历史桌面Chromium截图视为移动设备验收。Windows本地后端仍为主验收，Mac本地后端独立验证；Android/iOS浏览器连接已运行后端，不承诺手机数据库/原生App。本轮模型兼容修复不新增平台工程或公网连通配置。
