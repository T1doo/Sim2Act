## 页面使用

1. 打开已有授权 CSV 草案，在原 DAG 编辑器选择“有限节点组合”。保留三个节点：第一个改为读取 CSV，后两个为按列求和，后两个的来源都选择第一个读取节点，各自选择数值列，全部设为总是执行。保存计划后明确确认并运行，等待三份实际回执成功。
2. 点击“从本次成功流程准备版本”，核查两个稳定节点、各自允许列与预算、三份来源回执。勾选确认，保存内部版本；再单独创建实例。
3. 实例展示两组标有节点 ID 的列选择。分别选择本次列，勾选运行确认后排队。实际 worker 完成后点击只读恢复，查看同一结果版本中的两份完整结果。
4. 冷页面重新打开草案，读取已有版本与实例，选择实例并只读恢复；交换两个节点的列需再次确认，产生独立新 Run 与结果版本。以前结果保留。
5. 接受结果 UNKNOWN 时停止新提交，保留精确意图；用户手动恢复。已知接受后读取失败只恢复 GET，未知接受只能用同键同参数恢复，不自动重发。

双求和此轮只复用原固定材料，不提供新材料/无原内容逻辑的双列合同；原入口在 API 和页面明确拒绝。来源仍每次须可核查，撤权后保守停止。页面功能通过 JSDOM 和真实 loopback HTTP 验证，原生浏览器和视觉尚未验收。
