# 本地 CSV 文件到既有运行链（有限工程范围）

原 V5 产品设计的附加材料与 F1-T03、F2-T06/T08、AT-11/12 要求真实输入、可回读结果和持久运行。资源页原先只能粘贴文本；本轮补单个本地 CSV 的选择和核对入口，随后复用现有固定模板、预览、人工内部版本、实例、正常 worker 和冷历史。DAG 的内部发布链是另一项较宽缺口，本轮不扩展运行器。合成文件是工程证据，未获真实模型/用户材料/语义签收，不能称完整 P-A/P-B 或整体完成。

## 冻结合同

- 仅单个 `.csv`（扩展名不分大小写），名称最多200字，1–32768字节；严格 UTF-8，无 BOM、无空字节。拒绝其他编码、空文件、多文件或超限，不自动转码、trim 或改换行。
- 选择文件只使用浏览器 FileReader，不请求后台读取本机路径，不发送网络写请求。显示原文件名称、字节数、当前目标项目与文本。原文件内容另存页内缓冲，避免 textarea 将 CRLF 归一；用户修改任一字段则解除文件绑定，保存当前文本。
- 文件读取绑定身份、连接代次、项目、选择代次。取消、换文件、人工编辑、项目 ABA 或换身份后，迟到读取不得覆盖新表单。换项目/身份清理未保存内容；保留同身份/项目的未知 Save 意图，不借切换解锁重发。
- Save 仍为既有显式 POST，没有幂等键。页内冻结 body、防双击；网络失败、408/425/429、损坏或无效 ID 的回执保持 UNKNOWN，不自动重发。精确资源 ID 合法性检查不代表完整服务端来源证明。手动只读刷新列表核对，不凭相同 hash 冒认唯一接受；用户明确结束核对才能重新填写。
- 已接受 Save 的迟到回执保留原意图与 ID，需手动核对。已收到接受回执、后续列表读取失败不重复保存；迟到错误不能污染新选择。
- 材料 Save、创建草案、准备内部快照、人工确认内部 Release、创建实例与运行均为独立显式操作，不自动串联。原业务授权不改变：项目创建两条 artifact.save_text Grant，Save四条 owner/project-runtime 的 read/aggregate Grant，CSV草案两条 app-runtime 的 read/aggregate Grant；既有24小时期限不扩大。
- 后台/API/Schema/注册工具/执行器不改；实例仍固定材料，新运行输入仅为该材料另一数值列。新材料另需现有授权和内部版本步骤。内部 Release 不等于正式发布。

## 必要核查与边界

真实 HTTP 页面从磁盘合成 CSV 通过 FileReader 导入，无预置该项目材料、候选、Release、实例或结果；正常 worker 使用禁止模型的 provider。独立 CSV/Decimal 算术、资源 UTF-8 bytes/hash、真实持久 AppRun ID 和结果版本须对应。冷页面只读重开、零 POST。反例覆盖文件界限、读取代次、未知接受、瞬态4xx、无效 ID、保存与后续读回 ABA、人工文本模式。关联既有权限/来源/实例绑定及实际旧源码升级按必要范围回归。

精确冻结、双库结果、独审和失败保全以 [本轮证据](../evidence/local-csv-file-20261010/README.md) 为准。原 PG 图历史节点在基线667一次 PASS 仅说明本次未复现，历史超时根因仍 OPEN；原10秒门与 SQL observer 未改。HTTP200其余坏响应形式/入口及逐item历史map限制保留。Windows900/Edge240/Node150未验收；LIVE=0、PROJECT PENDING/BLOCKED_PARTIAL、语义 UNKNOWN、owner PENDING、整体 NOT_ACCEPTED、正式发布关闭。
