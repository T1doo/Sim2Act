# F2-T02 / P-A：有限非 CSV 目标到应用

2026-10-11；基线 `1dadba831a4d15fc164398e2f1070f22d7a5d77d`。
根代理为唯一产品写入者；独审只读。原 V5 产品方案、分阶段计划和当前剩余验收清单为依据。

本切片只支持 TXT/MD 的字面检索：输入一个非空、无首尾空白、至多 80 字符的词，返回所有含该词的完整行及行号。材料至多 4096 UTF-8 字节、64 行、匹配至多 16 行。独立检查器复核完整性、来源/hash/词/行号/原文。语义状态恒为 UNKNOWN；摘要、义务推断和任意语义目标不获得接受。

生成合同：冻结完整 GoalCard（约束、假设、未知、验收项均保留）、项目/用户/运行身份、材料精确版本和预算；服务端预分配 app/action ID。模型先选择唯一授权 resource.read，实际工具回执进入下一次请求；模型随后产出完整声明式 ActionSpec/AppManifest。无效候选进入一次有限修订，保留原始响应、诊断和 Attempt。至多三次请求、一个读取、一次修订。没有候选模板代替模型响应。

生产生成默认不可发送，LIVE allowance=0。工程验证只使用显式 test-only MockTransport；普通 MockModel 不伪装规划器。未知响应、缺 usage、超预算、取消、撤权、租约/版本竞争、迟到结果不产生候选；已 STARTED 未确认的发送不自动重试。结果只为 PARTIAL/candidate-ready，目标语义接受 NOT_RUN。

用户以精确候选指纹和 Run 版本确认创建预览应用，授权仅该材料的 resource.read 给独立 app 身份。独立来源记录绑定实际生成 Run 和原始候选；删来源、改 executor、重签候选不能降级。候选编译后使用已有隔离预览、精确内部 Release 审批和实例链。

`text.literal_evidence` 是显式登记的确定性纯文本变换，消费已经授权的材料读取；不是 intern.agent 的隐藏替代。其输入/输出/权限/版本被严格限定。已有 AppRun worker 执行并在同一事务复核当前授权、来源、版本、独立结果、追加回执和类型化历史。冷实例以新词得到新结果，不上传答案或 Replay；错误输入留下 FAILED 历史且不追加结果。

验证包括实际 SQLite Worker/进程内 HTTP、来源篡改、反馈与修订、冷实例新输入、错误输入和撤权/取消/预算/未知/竞争失败。必要页面提供完整目标→生成→指纹确认→预览/实例入口；离线 DOM 验证，无原生浏览器。真实模型、语义接受、Windows、PG、原生浏览器、完整 P-A/P-B 验收仍 NOT_RUN；不部署、不改 main/coredev、不强推、不配置凭据。
