用户以精确候选指纹和 Run 版本确认创建预览应用，授权仅该材料的 resource.read 给独立 app 身份。独立来源记录绑定实际生成 Run 和原始候选；删来源、改 executor、重签候选不能降级。候选编译后使用已有隔离预览、精确内部 Release 审批和实例链。

`text.literal_evidence` 是显式登记的确定性纯文本变换，消费已经授权的材料读取；不是 intern.agent 的隐藏替代。其输入/输出/权限/版本被严格限定。已有 AppRun worker 执行并在同一事务复核当前授权、来源、版本、独立结果、追加回执和类型化历史。冷实例以新词得到新结果，不上传答案或 Replay；错误输入留下 FAILED 历史且不追加结果。
