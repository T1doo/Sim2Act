# P-A 原准备永久结束与原键恢复（2026-10-16）

Goal 换版后，旧准备不能再批准；瞬时“未批准”也不能证明旧在途批准永远不会成功。本增量增加显式永久结束：完整冻结准备配对、当前双方 READ/SAVE、项目身份和全部既有批准/阶段/撤回记录检查通过后，在原事务/项目锁中写入 CLOSED 双记录。所有批准入口（包括旧完整合同接口）及实际批准验证均拒绝 CLOSED 或其残缺配对。批准先赢则结束拒绝，须原键明确撤回；结束先赢则迟到批准拒绝。原批准的版本、期限、权限校验不放宽。

页面正常未批准范围仍可明确批准，也可明确永久结束。另建只接受持久 CLOSED、已验证撤回或明确准备拒绝；瞬时未批准、丢回执及残缺配对继续锁定。Goal 变版可读取原键状态后明确结束，丢结束回执仅 GET 原键恢复。手工从 A 恢复 B 会同步地址；同意或撤回丢回执后重载仅 GET B。
