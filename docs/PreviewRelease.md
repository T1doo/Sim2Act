# Sim2Act · 当前合成工程桌面候选

本候选保留已认可的紧凑工作台、资源、目标卡、应用、实例及持久结果流程。精确应用提交与文件摘要以 `candidate-manifest.json`、`portable-manifest.json` 为准；桌面 EXE 和 SDK 摘要另见 `desktop-manifest.json`。构建、实际运行、业务验收分别记录，不互相替代。

## 桌面入口

完成 Windows 构建后，双击 `Sim2Act.exe`，显示独立窗口及任务栏入口。原后端实际 READY 后才显示工作台；关闭窗口通过私有控制管道请求原停止路径，核对同 worker 的 STOPPED、子进程真实退出和输出 EOF。失败保留数据与日志，退出未知保留运行锁，不强制终止或删除锁来重试。

新装配 ZIP 当前是桌面构建输入，状态为 `NATIVE_HOST_BUILD_REQUIRED_NOT_WINDOWS_EXECUTED`，尚未含新 EXE；须由维护者按照 `desktop-build/README.md`，用已有编译器、固定应用 SDK 和已有 WebView2 Runtime 在新候选目录构建。未构建时入口明确报缺项，不打开浏览器。最终交付须补当前 EXE 的实际 Windows 窗口、操作、关闭和重开数据证据。

依赖 Windows x64、已有 .NET Framework 4.6.2+、已有 WebView2 Runtime、Windows UCRT；不自动安装系统组件，不绕过安全拒绝。`Developer-Browser-Preview.cmd` 仅供显式开发预览。旧 Chrome 包及其截图属于旧版本，不是当前桌面软件验收。

## 本地数据与功能

将完整包解压到新的普通目录，不覆盖旧目录。使用公开合成身份 `public-synthetic-blank-workspace` 登录，只输入无隐私的合成材料。项目、资源授权、目标卡、应用与实例的审批和版本确认继续走原流程。`workspace data`、`webview-profile`、`temp`、`exports` 和日志位于应用目录；不能承诺操作系统、Defender 的系统记录绝不出现在目录外。不要复用公开合成身份处理真实项目。

已有 Windows 8210 源码回归通过两个全新进程的 P-A prepare/verify，使用5次固定 Mock，保留两份新材料及冷读结果；这不是新 EXE 或真实模型整链验收。Windows 6742 宿主已实编并出现“Sim2Act 工作台”窗口；当时页面操作、关闭与重开未完成，不能把窗口存在当成完整桌面验收。精确新版的操作与生命周期继续单独记录。

## 第一次在桌面中实际运行

以下是空白合成工作台的现有产品流程，不需要 PostgreSQL、模型密钥或任何模型响应。它与 `local_candidate_demo.py serve` 的已保存结果只读演示是两个入口；桌面启动的是可操作的 `synthetic-workspace`。

1. 双击已构建的 `Sim2Act.exe`，等后台连接完成。输入上面的公开合成登录并点“连接”；创建一个自己的练习项目。
2. 进入“资源”，名称填 `practice.csv`，类型选 `csv`，粘贴下列文本，明确点击“保存并授权项目内使用（24小时）”。也可显式选择同内容的UTF-8文件；选择文件本身不保存或授权。

```csv
item,amount,quantity
A,10,7
B,20,8
```

3. 进入“应用”，展开“直接创建 CSV 固定模板草案”，选择刚保存的材料并填写应用名称和目标说明，点“创建草案并授权读取”。材料保存与给应用授权是两次不同操作。
4. 选择 `amount` 并“运行新预览”，核对 `30` 和记录数 `2`。预览没有创建持久结果版本。继续“核查并准备内部快照”，核对精确内容后另行勾选并确认保存内部 Release，再在该版本行明确“创建独立实例”。
5. 在实例的“冻结材料的数值列”选择 `amount`，“提交新持久 AppRun”。等这次Run成为 `SUCCEEDED`，重新读取历史，核对结果 `30/v1`。再选择 `quantity` 明确提交第二个Run，核对 `15/v2`；第一次的Run与 `30/v1` 应仍在历史。
6. 可以从成功历史明确下载这次成果JSON；每次下载重新鉴权，不执行新任务。退出桌面窗口，等待后台正常停止。不要删除运行锁或数据库来解决退出未知。重新双击同一个EXE，连接、选择原项目和实例，只读找回同一Run与v1/v2；重开不重新创建项目、提交任务或初始化数据。

当提示 `GRANT_REVOKED`、版本冲突、配置缺项或请求回执未知时，按页面显示的具体原因核对。未知提交先恢复原键或读取既有历史，不能用连续点击另建Run代替；历史成功也不能代表当前新Run已完成。自然模型生成和正式发布在这个入口保持关闭；固定工具算对不等于目标语义已签收。
