# CSV 求和的本人适用范围声明

在“应用”目录打开单步 CSV 实例，选择数值列。需要对这次结果作人工声明时，先勾选“为下一次新 Run 事前冻结本人适用范围声明”，核对材料、列、Release 和实例修订，再明确运行。改列会清除勾选；新运行需要重新确认。不勾选也可正常运行，但事后不能给该 Run 补上事前范围。

结果完成后，在同一 Run 下点击“读取此 Run 当前声明及精确证据”，再准备声明。逐项选择接受或拒绝、填写理由，并另行勾选本人确认后提交。可以明确取消准备或撤回声明；历史保留。准备有效期为 15 分钟。

范围仅为固定 CSV 材料的所选数值列和结构化 `sum/count` 结果，不包含原普通任务的完整目标或 MD 报告。包括从普通成功 CSV 合同提取的 SUM_ONLY 应用；该应用在另授权材料上产生的新 Run 独立声明，来源报告的 PASS 或人工声明不会继承。

技术 `SUCCEEDED`、独立求和核查 `PASS` 与人工 `ACCEPTED/REJECTED` 分开保存。人工接受不改变原 Run、结果、目标语义 `NOT_RUN/UNKNOWN` 或正式发布关闭状态。普通预览只有可信聚合与类型校验；内部版本准备、Worker 和声明证据核查使用已有独立求和 oracle。

新结果、新 Release 或实例修订使旧声明失效为 STALE，旧记录保留。权限撤回后清除成果、历史数值和证据正文，仍可读取本人声明元数据并显式停止。丢失响应时保留原请求，在原 Run 下用原 key GET 恢复；不会自动重发或另建声明。

本轮只支持单步注册 `data.aggregate_csv@1`。未事前冻结的历史 Run、CSV DAG、模型节点和完整 MD 报告不能用此入口补签。没有新增 executor、Grant 类型、权限动作、真实模型额度或正式发布能力。

验证范围为合成 SQLite、实际 ASGI 请求和完整页面脚本的 JSDOM 手势；不是实际用户语义签收。PG、Windows、原生浏览器、真实模型、独立操作系统进程重启、远端 CI 和部署均未执行。排队撤权仍沿用 `WAITING_RESOURCE/GRANT_REVOKED`，本轮不重复其恢复矩阵。
