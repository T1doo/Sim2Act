# 浅色专业工作台 UI 规范

本文件记录 2026-11-04 用户最新系统性重构要求的落实，替代本轮早期的多色、粗边框和大面积磨砂视觉候选。业务契约、接口和运行权限继续由原控制器负责。

## 信息架构

- 全局顶栏：品牌、当前项目、查找、外观设置。
- 导航区：项目、应用、资源；项目内分区与历史属于次级导航，身份与健康状态位于底部。
- 配置区：一张连续表单卡片，顺序为任务类型、目标、材料、开始任务。主按钮是该区唯一实色主操作。
- 成果区：区域标题、执行状态、输出标题、实际结果、后续操作。来源/调用/验证/版本统一进入“检查详情”，复制仅在原能力允许时出现。
- 高级功能保留：CSV报告、完整回执、项目维护、应用版本/审批等继续使用原节点和控制器，按既有入口访问。

## 布局与密度

顶栏64px；宽桌面导航176px，中等桌面使用64px图标轨。指令区沿用280–420px可调宽度及344px默认值；分隔条12px并保留键盘替代。成果占据其余宽度，长阅读面上限1080px。

桌面主区外边距20px，配置卡片内边距20px，成果卡片24px。较矮桌面使用16–20px内边距和120px文本域，避免缩小文字。1100px及以下复用指令/成果切换；手机采用正常纵向流式布局，允许必要滚动。

## 字体

使用系统 Segoe UI、Microsoft YaHei UI、Microsoft YaHei。品牌仍为现有文字标识；不新增远程字体。

| 角色 | 字号 / 字重 |
| --- | --- |
| 页面与成果区域主标题 | 22px / 650 |
| 功能区标题 | 18px / 600 |
| 次级标题 | 16px / 600 |
| 目标输入与正文 | 15–16px / 400 |
| 主要表单标签、按钮 | 14–15px / 400–600 |
| 状态、版本和辅助信息 | 13px / 400–500 |
| 格式标记 | 12px / 600 |
| 关键结果数值 | 30–32px / 650，等宽数字 |

不用多种装饰字体建立层级，不以大面积小字号换取紧凑。

## 表面与颜色

| Token | 浅色值 | 用途 |
| --- | --- | --- |
| `--canvas` | `#EEF4FB` | 工作台底色 |
| `--surface` | `#FFFFFF` | 主内容与表单 |
| `--surface-soft` | `#F6F8FC` | 导航、表头、材料行 |
| `--ink` | `#18283B` | 主要信息 |
| `--muted` | `#516277` | 辅助信息 |
| `--accent` | `#2965AD` | 主操作和当前入口 |
| `--accent-soft` | `#E8F0FB` | 选中与轻反馈 |
| `--line` | `#D6E0ED` | 装饰性边界 |
| `--control` | `#7488A1` | 必须可辨的控件边界 |
| `--focus` | `#1D4F87` | 键盘焦点 |

深色模式有对应完整语义色，不直接对浅色结果反色。控制圆角6px、次级容器8px、主容器12px；主卡片使用1px轻边框与轻阴影。主配置卡片内不再嵌套多张装饰卡片。

## 控件与状态

主按钮40px、主要表单36px、工具与次级动作32–36px。触摸模式扩大目标；长中文可换行或通过可操作入口读取全文。材料名称查看与移除是不同操作；材料发生真实变化时才重建选择摘要，保持无变化刷新时的焦点。

Hover仅改变颜色/边界，按下允许1px视觉反馈，焦点保持2px外框。Disabled使用原禁用语义与清楚文字。Loading沿真实请求显示，不通过动效假装完成。状态颜色必须伴随实际文字。

背景取消网格与高饱和光带，仅保留低对比浅蓝氛围；动态可停、后台停动、减少动态关闭。任何动画不决定请求、结果、批准或恢复状态。

## 工程组织

`app.css` 保留原业务场景基础规则，将多轮视觉补丁替换为单一“Professional workbench system”部分，集中管理token、外壳、配置、成果、目录、浮层和响应式规则。`app.js` 只重组原DOM及工具入口，不重写业务控制器。

当前验收证据见 [系统性重构记录](../evidence/frontend-system-rework-20261104/README.md)。三秒识别目标属于设计目标，未进行独立用户计时研究。
