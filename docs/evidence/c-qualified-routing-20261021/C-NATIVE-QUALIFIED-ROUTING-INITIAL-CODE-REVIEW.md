# Qualified native routing: initial code findings

Static inspection only, while the sole writer was applying fixes; this is **not a final frozen-source ACK**. Reviewer executed no product imports, C build, tests, DB, Worker, Mock, G0, profiler or signals and edited no repository files.

The reviewed selector uses bounded C arrays, counts every visit before primitive/memo handling, checks active before completed memo, and keeps the projection in the same C entry after qualification. It reads remaining Python/C recursion state without changing it. The new runtime fallback returns from selectors before invoking the original helper at `input_bytes`, and leaves the original helper function identity intact. Actual qualification/routing evidence is still required on final bytes.

Concrete issues sent to the author:

1. **Namespace lookup before key qualification.** Initial `static_member` used `PyDict_GetItemString` directly on type namespaces. A colliding foreign key can execute equality before the proposed no-Python-evaluation interval has been established. Moreover that API can suppress lookup exceptions. Required repair: bounded native-key qualification before lookup and explicit-string `PyDict_GetItemWithError`, propagating unexpected errors. Subsequent source read shows invocation-local namespace qualification plus that error-aware lookup.
2. **Absence versus unsuitable MRO.** Initial NULL conflated a genuinely absent metaclass descriptor with long/unsupported MRO or failed scan. The metaclass-fields guard interpreted NULL as safe absence. Subsequent source read shows a separate `namespaces.ok` rejection for unsupported MRO; complete scans, budget and error exits still require final review.
3. **Same-class backend method shadow.** Initial `typed_candidate.select(...)` dispatched an ordinary instance attribute before any backend/helper qualification. An exact `_QualifiedBackend` instance could hold a Python callback named select. Subsequent source read shows slots, an issuer marker, fixed-entry `select_candidate`, class method identity and static native-module dictionary lookup. Tests must establish unknown/forged state selects Python before callbacks.
4. **Current recursion budget read too late for wrapper frames.** Selection enters two Python wrapper frames and roots/nested helpers before the C state read. A remaining-stack-80 test demonstrates ordinary conservative fallback, but not the extreme low-stack boundary. A partial model can give an early original AttributeError while the additional pre-budget frames could instead exhaust recursion. A tiny no-extra-Python-frame conservative probe before the second wrapper, or an equivalent route, plus low-stack/partial-model differential evidence is needed before claiming unchanged fallback resource/error semantics. This point was still outstanding when this initial report was saved.
