# Complete outside capture: temporary record allocation and lifetime

The incoming Source table remains unchanged. Outside traversal still executes the complete original type/range/cycle, RowMapping/quoted virtual metadata, Limits, parent discovery/order, node/edge/depth/leaf budgets and real/virtual identity rules. Outside-only nodes now use a negative joint-memo ref plus their type and budget entry. Their full nodes/origins/kinds/external records were discarded before output anyway; these records are no longer allocated. Positive incoming refs and their full shared-descendant marking, anchor ordering and emitted data remain unchanged. Strong refs remain until capture has produced its data/anchors/parents. No outside scan is skipped or cached; graph checks, match_live, authority/revocation, deadlines and atomic writes are untouched. This is not the proposed larger scan-fusion architecture.

The recursive local visitor also formed a function→closure→function cycle retaining temporary structures after normal return until cyclic GC. Explicit self recursion through a per-call parameter removes that cycle while preserving original recursive call order. The enclosing capture frame still holds every required temporary through output construction. Actual old/new weakref observations show original walker alive after normal return until gc.collect; new walker already released. Exception tracebacks can still naturally retain failed call frames. Production GC policy is not changed or disabled.
