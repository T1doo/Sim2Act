Original SQL, current authorization/revocation, finite deadlines, stop, model/max-output, connection/transaction/scope, lease/fence, epoch and receipt checks are unchanged. ## Shared topology and unsupported representations

Common-memo capture preserves cross-family **same-projection** JSON dict/list/tuple sharing. Hidden RowMapping data storage and its sharing with visible JSON are included in sidecars. Tests prove common nodes object **and** identical node ref, never only equal integers or Arena structural equality. Typed/raw immutable leaf sharing is retained. This is not a claim of RowMapping visible-projection object identity, nor arbitrary model.__dict__/raw mutable sharing. A model storage alias or mutable object requiring different typed/raw projections is conservatively outside this optimization representation and chooses common LEGACY **before either handle exists**. It does not create a new business rejection or silently split such an alias.

The Arena materializes only each role root's reachable nodes/tables; unreachable/foreign refs fail closed before hash/equality. Registry/scaffolding, sidecar slices, joint wrapper, views, alias qualification and extra reachable metadata are charged before construction. Total joint nodes/edges/depth/leaf/encoding and overlapping logical reservations are checked before issue. On pre-issue capacity failure, both roles use their same original completed facts and no producer reruns. Already-created Arena/receipt/joint references are released before the ledger reaches zero. No capacity catch surrounds issuance or later consumers: errors there close the mode instead of falling back.

All limits here are the existing explicit finite **fixture** Bounds/Limits, not product capacity qualification, RSS, a CPU hard quota or a disk hard quota. Conservative two-view accounting increases reservations; that is reported below, not disguised as production-ready bounds.

## Precise remaining interface boundary

That is not solved or changed here. The previous snapshot/borrowed-value counterexamples remain applicable; no borrow/PASS cache or lease extension was introduced.
