## Clone and pure-execution conditions

The clone must preserve full actual model storage, including **all** fields (None fields included), exact actual container/numeric types, independent `__pydantic_fields_set__`, and the existing extra/private rules. None omissions belong to serialization, not construction of the private model storage. Use exact fixed classes and callback-free storage access/copy, not instance `model_copy`, `model_construct`, arbitrary Mapping iteration, or `deepcopy` hooks. Completed-DAG memo must retain aliases without hiding active cycles; use invocation-local references only. For a complete native Run row, use the existing controlled visible RowMapping projection before copying; do not introduce unsafe `dict(row)` or a new hidden-row proof shortcut. A shallow top-level dict with live nested aliases is not a complete private snapshot. Nonfinite values and previously unsupported schema data must reach the existing original parser/rejection behavior rather than a new broad clone cap/business rule.

Serializer qualification is necessary but not sufficient for the assertion that the original policy core is pure. `_requirements` invokes `model_validate` and compiled Pydantic validators; `_run_check_from_facts` constructs RunCheck. State the fixed original validator/source contract and conservatively route unqualified changed class-method/validator metadata to the old path if those replacement cases remain supported. Do not run an unknown validation callback inside the new closed pure segment merely because its serializer is standard. This is a bounded fixed-function contract, not a request for a platform code-tamper framework. Exact model/serializer fallback semantics from the earlier streaming slice remain relevant.

## Why `_fields` should remain separate in this slice

`_fields:2671-2676` has one runtime call at `_prepare:2824`; it is not recomputed by each ordinary `check`/`_recheck`. Its owned assembly contains eight `_read_fields` calls, five `_dump` calls, two `_accounted_fields` family assertions and a dynamic owned `generation.run` leaf. The legacy accounting branch adds its own per-chain/full-row dumps. `_read_fields:2642-2645` dispatches `facts.fields()` dynamically; `_dump:2637-2640` dispatches instance dump, each followed by `_base`. Simply disabling their pins inside existing dynamic dispatch is not a fixed pure core.

The fields bodies have no SQL or clock, but their complete recursive closure must be fixed explicitly: `_ColdSourceFacts`, `_ColdSourceTyped`, `_ColdSourcePrefix`, `_ColdSourceAuditFacts`, `_ColdSourceAuditPrefix` (`pb_natural_specs.py:401-432,653-701`); `_ColdExtractionPrefix`, `_ColdExtractionReview`, `_ColdExtractionAuditPrefix` (`:1125-1159,1356-1375`); `_ColdUseBoundPrefix`, `_ColdUseReviewFacts`, `_ColdUseAuditPrefix` (`pb_natural_uses.py:331-414`). ReviewFacts accesses its ReviewPrefix guard, not ReviewPrefix.fields. Nested serializers include Limits, RunScopeInput, Metadata, ExtractInput, GoalCardRunSource and CommitInput; current `_trial_typed_nested_classes` does not include RunScopeInput or Metadata. Fixed-dispatching only the top method leaves nested dynamic `.prefix.fields()` calls. Existing fields return complete shallow projections with many live row/dict/model aliases; they are not immutable private snapshots.

Therefore first implement and prove only the two policy wrappers. A later fixed `_fields` assembler needs its own explicit exact fact/model catalog and complete projection equivalence, retained typed/raw alias rejection, correct owned-family association/dynamic leaf behavior and complete snapshots for pure consumption. It must preserve original public fact methods and standalone guards. This is a concrete remaining boundary, not a claim that such assembly is impossible or that a new ownership architecture is necessary for the two policy wrappers.

Necessary local evidence for the two wrappers: reference value/full error equivalence; complete pre/post pin order/count; fixed constructor/serializer replacement chooses original path before callbacks; private clone alias/DAG/cycle/header/fields-set correctness; original-domain malformed input priority; source/raw/typed mutation, settings, stop, registry/link changes before publication rejected at exit; same original exception object and scope invalidation; no new SQL/clock/producer calls, and no replay after pure failure. These are proposed tests, not reviewer executions. No G0, lease change or new window is needed to establish the local contract.
