## 真实运行范围

实际前端与 API 均来自本工作区，浏览器报告 Windows/Win32 Chrome156。Windows Python3.12.10 依赖来自仓库已有包；`_raw_snapshot` 复用前核对其 C 源码与原包记录完全相同。

标准新合成工作台第一次启动实际失败：`DomainError: UNSUPPORTED_CAPABILITY — Qualified native lease control is unavailable`。没有替换原生资格门，也没有把这个启动记作通过。随后使用仓库现有 `local_candidate_demo` 的显式 `Store(test_only=True)`/文件SQLite工程入口运行当前 API 与前端，新建独立合成数据，复用原确定性CSV Worker。此入口不是完整原生桌面或正式数据库验收。

准备阶段实际创建材料、应用、内部版本和实例，通过正常 Worker 保存金额30/v1。浏览器中又实际提交人数列：202接受新Run，原Worker在原任务期限内处理为SUCCEEDED，人数5/v2。页面刷新后，新Run与30/v1历史均保留。运行ID与回执见 [接受回执](new-run-acceptance.json)、[页面回读](new-run-result.json)。这两次计算均为确定性工具，真实模型调用0；测试服务没有常驻模型worker。

## 未验证与实际限制

- 683×384与341×384是200%/400%的CSS回流等效条件，不是Chrome菜单缩放实测；125%/150%原生浏览器缩放也未签收。Windows computer-use 已列出本项目Chrome窗口，但在读取窗口时因无法可靠确认URL而停止该轮控制；未绕过或修改安全设置。
- WebView2/WinForms独立窗口、Windows原生DPI、原生关闭重开、完整新工作台原生租约模块仍未通过本轮验证。当前测试入口与标准新合成工作台不同，不能拿它替代后者。
- 真实剪贴板、读屏、高对比模式、触屏实机、动效帧率/耗电与长时间性能未验。浏览器无未捕获脚本异常；原有favicon.ico 404仍可见，故没有声称控制台完全零错误。
- Source/Cold全链、人工锁定全组合、真实模型、正式PG、任意目标语义及全部42项整体验收未重跑；已有受控回归和确定性CSV不能替代这些结论。
- 本轮源码未提交、未推送、未合并main、未部署或发布。测试数据库、解压依赖及临时启动脚本保留在忽略的`.local/frontend-review/`，没有修改用户已有数据。

当前本地测试预览为 `http://127.0.0.1:8765`，公开合成登录 `public-synthetic-local-candidate`。这是当前会话的临时工程服务，常驻worker未启动，适合查看本轮页面与保存历史；不是完整产品启动承诺。
