## 外部验收与最高价值下一步

AT-01 的目标 Win11 原生、普通运行身份/PowerShell/安装/启动/停止/重启与实际 Edge
900/240/150 标准仍需要目标环境实测。Linux 的 PostgreSQL、JSDOM 或沙箱 Chromium
均不能替代。历史 LIVE 证据不提供本轮额外预算；一般真实任务、模型/用户价值、
通用语义和人类签收仍待明确授权材料、预算与独立 oracle。F1 前置和 F2 正式门不因
此次回归放行。

下一步优先做一个**现有非 CSV 应用明确要求变更的实际闭环**，先冻结封闭 schema、
应变/应保留对象和独立检查，再把新补丁接入原图与真正检查派发；同时使相关
PROJECT 扩验作业有真实回执和受权终态，而非继续增加状态面板或重看旧基线。
若现有执行器无法在 LIVE=0 下产生新成果，明确列出需单独批准的模型预算或可信
动作合同，不能偷偷加注册、Grant、任意代码或业务写权限。并行的外部验收优先项
是当前精确提交的 Win11 普通用户安装/重启/Edge 验证，不再用旧 Server/Linux 计数代替。

本报告只梳理下一步，本轮不实现外围功能、不启用 LIVE/CI/部署。
