## 文件与可见范围

- material_a.txt、material_b.txt：每个文件5行、ASCII/UTF8，中性虚构场景。原始LF及末尾换行属于冻结字节。
- goal_drafts.json：每份材料的全部Goal卡字段草案；resource_refs含明确未绑定占位符，当前不应提交。其余字段是原方案中的自然语义任务要求，不新增执行器、工具或权限。
- RUBRIC.md：可供独立人工评审采用的标准草案，机器校验与人工语义结论分开。
- score_sheet_a.md、score_sheet_b.md：两份空白独立评分记录，当前所有结果NOT_SCORED/PENDING。
