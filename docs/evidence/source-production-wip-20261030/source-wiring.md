# Post accounted-Source wiring closure

This is the complete fact family returned by `_graph_stage_accounted(...,
'source')` in a post graph. Other Source audit/origin facts remain on their
original complete checks. Pre/Generate are unchanged full paths. No permission,
account entitlement, successful authorization or old Graph is carried forward.

| Producer/consumer | Post Source representation and retained check |
|---|---|
| `dispatch._graph_stage_accounted` | Original SQL/J/NS producer and all raw-domain/typed joins complete first. Independent import-time caller check runs before replaceable Source helpers. One native live/full-storage/alias handoff then publishes the native binding pin. |
| `gate._graph_trial_accounted_models*` | Checks the same scoped binding/pin. No Source Slot/Capture/BodyArchive is added to the repeated cohort. Original raw/model gate runs once at publication. |
| `gate._graph_trial_stage_models_from_raw`, `stage_raw_from_raw`, `stage_current` | Owner-backed Source Run/actual/chains/NS reads, original binding/generation/extraction joins, independent Source usage calculation and original SQL authority construction. |
| Runtime `_prepare`, `_accounted_fields`, `_fields`, `_typed_parameter_models`, policy phase-source ID check | Source KEY and complete.source share the same native pin. All Source data reads come from its immutable owner. Journal Ledger/QuotaCursor and Generate remain fully checked. |

The separate native control binding holds the exact graph, inputs, role limits,
binding, connection, transaction and scope roots, with nonce/epoch/phase. Its
Graph pin contains only a unique binding ID, complete immutable metadata and
original leaf carrier, and shared outside anchors. Anchors retain the original
whole-graph checks; the immutable Owner contains no borrowed models/rows/dicts,
Graph or successful validation result.

Static C views cannot be subclassed or monkeypatched and do not dispatch Python
view methods. Constructor grammar checks cover child types, ranges, cycles and
reachability before view dereferences. Native `match_ledger` selects from the
actual current Ledger and compares both Source Slots/Identity/Outcome storages
with one alias memo inside a bounded GC-disabled/GIL-held interval; it does not
consume Slot objects saved before a callback. Original guards remain before and
after it. Original automatic-GC state is restored on every return/error path.

code, wrapper closure cells and imported pure helpers. It is not a remembered
content PASS. Qualified source inventory now includes `.h` files as well as
