# Sim2Act · 方向 3 提交准备清单

## 材料主线

产品书与影片统一沿着「Sim 构想 → 2 转换 → Act 可用应用」展开，完整正式设计见[产品书 V2](产品书与技术主线_V2_审阅稿.md)。重点解释自然语言如何转成规格、动作和界面，以及应用怎样运行、复用和维护。工程实现与实验另列附录。

| 评分项 | 材料怎么准备 |
| --- | --- |
| 实用性 40% | 讲清谁在重复做什么、哪一步麻烦。用可回看的两次结果说明复用价值。尚无用户对照数据时，把节省时间写为验证目标。 |
| 完整性 30% | 提供体验入口、版本、启动方式、样例输入、操作步骤、预期输出和已知限制。用接收方身份核对视频网盘与体验链接。 |
| 技术实现难度 30% | 用书生生成候选和两次运行的记录说明模型承担的步骤。写明实际使用的运行时、权限检查、回执、来源核对和版本记录。 |

## 提交前逐项核对

- [ ] 从官方渠道确认截止日期、具体时刻、文件名日期格式及团队字段。
- [ ] 确认托管书生 API 的权重说明口径和可接受的应用体验链接形式。
- [ ] 固定提交用源码版本、体验方式与依赖。由接收方按说明复现一个实际运行案例。
- [ ] 完成技术 PDF，插入实际视频网盘链接和应用体验链接。
- [ ] 导出成片，核对时长不超过 5 分钟、分辨率不低于 720P。用接收方账号或无痕窗口实测链接权限。
- [ ] 准备关键代码和模型 ZIP。记录模型身份、来源、权重或托管说明，核对数据、开源依赖和素材许可。
- [ ] 解压检查内外两层 ZIP。核对是否含密钥、私有数据库、个人数据或开发日志等无关内容。
- [ ] 按规定命名外层 ZIP，上传并核对最终提交状态。
