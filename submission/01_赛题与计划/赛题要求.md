## 赛题与参赛方向

主题是推动大模型从内容生成走向自主执行，面向科研、行业和开放生态建设可落地的智能体。参赛作品必须基于上海人工智能实验室的书生大模型，可选用 Intern-S2 系列、Intern S1 Pro、InternVL 等模型，结合任意 harness。OpenClaw、Hermes、Claude Code、LangGraph 是示例。MCP、A2A、Agent Skills、多智能体协同、上下文与长周期记忆、GUI 操作均为可选创新手段。

| 可选方向 | 核心要求 |
| --- | --- |
| 1 · AI4S 科学智能体 | 面向「搜、读、算、做、写」，覆盖文献和科学数据理解、工具调用及假设、实验、验证与迭代。 |
| 2 · AI＋新场景智能体 | 面向工业、城市、医疗或教育之一，形成感知、决策、执行闭环，能工程化调用。 |
| **3 · 开放赋能智能体（Sim2Act 选择）** | 自主选题，解决实际痛点，完成需求拆解、工具编排、自主规划与稳定输出，交付可运行、可复现、可落地的轻量复用方案。 |

鼓励自行准备行业或应用数据集，作为开发和效果验证材料。使用书生 API 时，可在注册后提交「申请更高流控」，按用户提供的赛题说明备注「兴智杯+团队名称」，审批由平台核实。

## 评分标准

| 主题赛维度 | 权重 | 关注点 |
| --- | ---: | --- |
| 完整性 | 30% | 全链路要素、文档规范、成果可复现性 |
| 实用性 | 40% | 解决实际问题、适配场景、科研或市场价值 |
| 技术实现难度 | 30% | 书生和工具链融合深度、技术应用深度与创新度 |

总决赛综合评估团队表现、创新性、完整性、落地可行性、市场潜力、应用情况和实际效益。

## 提交格式

- 外层 ZIP 文件名为 `单位简称-作品名称-队长姓名-队长手机号-日期.zip`。
- 第一项为**技术文档 PDF**，内含介绍视频的网盘链接、应用体验链接等。视频时长 **5 分钟以内**，清晰度**不低于 720P**。
- 第二项为**关键代码和模型文件 ZIP**，注明模型权重。模型文件过大时，可使用网盘链接，下载地址单独写在 Word 或 TXT 文件中。
- 以末次提交的有效作品为准。准确截止时刻、日期段写法、托管 API 的权重提交口径和接受的体验链接形式待官方确认。

## 参赛与赛程

- 面向国内外团队及个人开发者。团队最多 5 人，同一选手同一赛题不得重复参赛，相关支持单位不得参加本赛题。
- 报名信息须准确、真实、有效，团队名称须合规。作品须原创、真实、准确、完整，符合相关法律法规、产业政策和第三方开源许可证要求。参赛作品相关知识产权归参赛团队所有。
- 用户提供的赛程为 8–11 月主题赛或专项赛，按官网及官方公众号通知执行。总决赛计划于 12 月在深圳现场答辩。
- 主题赛支持书生 API 及端砚 TokenPlan 算力机会，后者优先面向方向 1。另有证书、周边和实习面试机会。总决赛有案例宣传、合作对接与政策支持机会。
- 赛程和交流可关注「兴智杯全国人工智能创新应用大赛」和「人工智能创新应用洞察」。申请加入赛事群时按赛题说明备注姓名、单位和赛道名称。
