# 相关工作与比较定位

2026-11-07核对原始资料。以下描述既有能力，比较栏是Sim2Act待检验的问题，不是已经测出的优胜结论。

| 对象 | 原始资料确认的能力 | 本作需要检验的增量价值 |
| --- | --- | --- |
| Dify | 工作流可组合模型、工具、分支、触发与人工审核 | 目标形成规格时，界面、动作与检查是否一致，人工配置量如何变化 |
| Lovable | 自然语言构建、迭代与部署全栈应用，包括可编辑代码 | 受控动作、结果来源和局部维护是否降低错误绑定与返工 |
| Agent Workflow Memory | 从经验诱导可复用工作方法并辅助后续行动 | 参数化应用、专用UI、权限与新输入独立性带来什么可测改变 |
| LangGraph | 检查点保存线程状态，store保留跨运行数据 | 业务操作身份、效果核对和应用/结果版本归属的具体保证 |
| Bazel Skyframe | 依赖图与增量计算；未登记的读取依赖会破坏正确性 | 语义不确定、动态读取和人工锁定下的漏改、误改与扩验 |
| ChatDify | 2026-11-01预印本摘要提出自然语言规划、Schema增强DSL编译和闭环核验 | 作为近邻机制比较，需同条件复现后才能比较效果 |

来源：[Dify Workflow Studio](https://www.dify.ai/workflows)、[Lovable官方介绍](https://docs.lovable.dev/introduction/welcome)、[Agent Workflow Memory原论文](https://proceedings.mlr.press/v267/wang25bx.html)、[LangGraph持久化](https://docs.langchain.com/oss/python/langgraph/persistence)、[Skyframe](https://bazel.build/reference/skyframe)、[ChatDify摘要](https://arxiv.org/abs/2611.01563)。

本轮没有执行这些产品或论文的对照实验，没有移用其成功率，也不使用“首次”“独有”等无证据结论。正式比较应冻结模型、材料、工具、预算及人工介入规则，报告样本数、失败和首次构建成本。
