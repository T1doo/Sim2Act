# Sim2Act v08 · 服务器唯一入口

本包是270秒影片的制作输入，不是已生成视频。组合：产品书v05、影片v08、业务事实v03派生的事件修订版、冻结工程证据v02。旧v07用于历史归档，本包无须下载旧266MiB包即可开工。

1. 在解压根目录执行 `python checks/verify_package.py`，并核验SHA256SUMS.txt。阅读 `film_manifest.json`、`asset_manifest.json` 和 `business_facts.json`。
2. 阅读 `product/Sim2Act-Product-Book-v05.pdf`、`导演表_270秒.csv`、`旁白稿.md`、`style/影片字版规范.md`。各镜入口为 `shots/Sxx/shot.json`，精确合成详见同目录composite.md。
3. 使用服务器已有批准模式与资源，不重选模型，不修改Park队列。Ref2VA为优先请求，能力未在Windows端验证；只对 requires_generation=true 的16个单元调用H3，其他11个单元无需生成背景。实际支持参数现场核对，项目schema不是API请求字段。
4. 先排 SIM-D1（S04/S11生成，结合S05/S10原UI）、SIM-D2（S14/S15）、SIM-D3（S19/S21），内部检查通过后继续其余镜头，无需逐镜等待用户确认。新增付费、未授权GPU或事实冲突集中说明。
5. 定稿UI与工程证据按原hash直接采用。5张新母版用于人物/屏幕/机制动作；不是实际客户纪实或新增运行证据。机制物体是视觉比喻，不表示Sim2Act需要硬件。
6. 主编辑线24fps，270秒=6480帧。每单元编辑10秒，生成请求8秒，实际时长/fps/帧数均待取得文件后用ffprobe记录。源片按所需动作取用，禁止循环、长定格或改fps头凑时长；短源片不足就调度必要补片或合理剪辑，保持关键状态阅读。
7. 静帧预演 `精确交互预演.html` 检查操作与状态；它不包含真实H3动作或正式声音。生成窗口与参考图在shot.json中，必须按composite.md将实际动作插入，不能把整份预演录屏当成主片。
8. 字幕是时间草案，正式配音按章节连续录制后重对齐。S01、S24已改词，没有复用v07临时音轨。生成原声实际试听，连续配乐记录许可，完整成片人工听审。

关键停留：S17报告167–170；S18发布未运行173.5–175.5；S20新版未运行193–195；S21结果3在200–205、随后历史；S26明确查看既有结果3，不创建新run。秒数是编辑目标，落帧按round(t×24)，最大误差半帧；事件顺序不可改变。

二维码264–270稳定保留，正式压缩后再次扫码。产品书中的应用Release为Windows开发预发布，视频外链尚待成片填写。工程记录的PARTIAL、INTERNAL_ENGINEERING_ONLY、语义未验收与人工待签收不得修改。

若接口不支持期望模式，保留未生成状态并记录具体能力差异，不能悄悄拿旧背景模板代替。全部生成完成后输出实际模型/参数、源片时长/fps、所取区间、失败返修记录和最终成片校验。
