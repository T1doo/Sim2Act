# Sim2Act · 三分钟影片规划 V1

当前执行[四分半影片 V3](四分半影片制作说明_V3.md)，总时长 270 秒。本文件仅保留历史三分钟结构，不作为生成依据。

本稿为审阅用结构和视听计划。参考图定稿后再生成完整逐秒表、分段 H3 提示词和旁白成稿。

## 影片方向

片名暂定「让专业经验成为会行动的应用」。整体采用科技产品发布片的节奏。开场给出工作压力，中段展示一次完整的应用生成和使用，高潮是规则改变后的局部更新，结尾把个人能力连接到团队和社会价值。

旁白采用沉稳、清晰、有呼吸的普通话播音式表达。保持自然重音，让“生成应用”“换一份材料”“保留已有成果”等动作词突出。初稿约 600–720 个汉字，后续以实际朗读控制在 180 秒内。界面停留和转场要留出观看时间。

画面为 16:9，建议最终交付 1920×1080。片头与片尾可用深色空间、蓝紫光与暖金焦点，中段保留浅蓝乳白产品界面。音乐从稀疏钢琴和低频脉冲进入稳定电子节拍，关键结果出现时降低强度。最后一句留出完整收尾。

## 视觉节奏与转场

每个镜头只安排一个主要注意点。复杂 UI 用正面视角，先停留约两秒让观众找到区域，再表现点击或内容变化。卡片成形、应用交付、影响传播、团队能力汇聚作为四个视觉亮点。

跨镜头通过同位置卡片、同一来源线或同一个应用图标衔接。大幅运镜只用于建立场景和片尾，数字与原文出现时保持稳定。转场记录进入点、结束点、前后主体位置、色彩和声音衔接，剪辑重叠计算在 180 秒内。

## 逐秒表的交付格式

下一轮输出 `逐秒时间轴.csv`，包含 180 行，每行覆盖一个一秒区间。字段包括总片秒数、单元 ID、局部时间、参考图 ID、构图、主体动作、镜头运动、屏幕文字、旁白片段、音效、音乐和转场。停留也要写清具体保留的画面。

例如 S08 的规划粒度如下。

| 局部秒 | 可见变化 |
| --- | --- |
| 0–1 | 成果卡保持静止，问题条目位于右上区域 |
| 1–2 | 光标移向问题旁的来源按钮 |
| 2–3 | 点击，按钮产生短促反馈 |
| 3–4 | 右侧来源栏沿边界进入 |
| 4–5 | 原文段落在固定位置完成显示 |
| 5–6 | 对应条款出现轻度高亮 |
| 6–7 | 问题与条款间的细线完成连接 |
| 7–8 | 静止阅读，旁白说完依据关系 |
| 8–9 | 光标离开文字，画面继续停留 |
| 9–10 | 保持来源栏完整构图，为下一镜留下衔接位置 |

逐秒表是导演和剪辑约束。H3 提示词会将这些动作组织成连贯自然语言，实际时序以生成片段复核。

## 参考图和提示词的对应

每段一个独立文件夹，包含选定图片、素材映射、官方格式提示词、旁白和该段时间表。图片可跨段复用，但在每段提交时重新列清上传顺序与标签。原图像素尺寸、构图、安全区和品牌位置统一检查。

参考模式优先由素材关系决定。固定首帧用 I2VA，明确首尾状态用 FL2VA，多张图分别约束界面、风格和环境时用 Ref2VA。全参考模式的六个字段和标签规则见[H3 使用规范](H3技能配置与制作规范.md)。

## 进入视频生成前

完成连续静帧预演，旁白朗读和时长核对；冻结参考图、屏幕文案与提示词版本；选取开场、一个关键 UI 动作和一个跨场景转场作为小样。用户审阅小样后，再依次生成剩余单元。最终拼接时核对同一主角、品牌、字幕、音色和背景音乐的一致性。
